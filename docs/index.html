DFPS Spending vs. Services: Data Quality & Reconciliation

A SQL pipeline that integrates nine years of Texas Comptroller expenditure data for the Department of Family and Protective Services with DFPS Data Book service volumes, applies 15 documented data-quality rules, and proves every dollar reconciles to its source before any analysis is reported.

Built by Tejaswi Yadala · Source code & SQL on GitHub · Data pulled from data.texas.gov on

Independent portfolio project using only public, aggregate data. Not affiliated with or endorsed by DFPS or the Texas Comptroller. No confidential or case-level information is used.

2. Data-quality scorecard

Each rule runs in SQL (sql/03_data_quality.sql) per fiscal year and records the rows checked, rows failing, dollars affected, and the action taken. Nothing is silently dropped.

3. Reconciliation controls

Each check compares two independent figures that should agree (sql/05_reconciliation.sql).

4. Method & caveats

  • Pipeline: extract (Socrata API) → raw layer kept as received → reference data and crosswalks → staging that conforms 5 different yearly layouts → 15 quality rules → reporting marts → control-total reconciliation → this dashboard.
  • Spending is the Comptroller's "State Expenditures by County" for agency 530 (DFPS). County reflects where the Comptroller attributes the payment, which is not necessarily where services were delivered.
  • Services are DFPS Data Book counts: children in DFPS legal responsibility during the year, removals, CPI alleged and confirmed victims, and APS completed investigations.
  • Accessibility: every chart has a text alternative and a data table, colors meet WCAG 2.1 AA contrast, and the page follows the system light or dark setting.
